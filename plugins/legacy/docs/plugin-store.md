# Магазин и плагины · 0.6.7.7

Каталог по умолчанию: `https://ttcuz.ttcuz1337.workers.dev/plugins/catalog.json`. Можно указать другой HTTPS JSON-каталог или очистить адрес, чтобы отключить магазин. Минимальный JSON — `{"plugins":[]}`; пример: `examples/plugin-catalog.json`.

Запись содержит id, name, version, author, about, tiktok, url, icon и sha256. Относительные URL разрешаются относительно адреса каталога. Каталог, иконки и файлы используют HTTPS без учётных данных в URL. ID: до 80 латинских букв, цифр, точек, подчёркиваний и дефисов; начало — буква или цифра. Не более 100 записей. SHA-256 полного `.ctt` сверяет полученные байты с каталогом и не удостоверяет автора.

## Установка и включение

Выберите «Плагины → Установить файл». Файл устанавливается сразу, без экрана статической проверки. После установки он выключен; включение переключателем запускает его без запроса возможностей. Нет запретов Runtime.exec, загрузки дополнительного кода/нативных библиотек, native-методов, рефлексии, сети или обфускации. Переименование классов, отсутствие SourceFile и закодированные строки сами по себе не мешают установке и публикации.

Ограничения формата сохраняются: архив плоский, обязательны manifest.json (до 64 КиБ) и classes.dex (до 16 МиБ); icon.png необязателен (до 1 МиБ). Общая загрузка — до 18 МиБ. Лишние/повторяющиеся файлы, выход из папки и повреждённый DEX отклоняются. Проверяются заголовок, контрольные суммы и доступность структуры DEX. Entry должен существовать и реализовывать MargyPlugin; min_api и указанная версия TikTok должны соответствовать приложению. Android 14 требует read-only DEX перед загрузкой — это сохраняется.

Плагин выполняется внутри TikTok с его правами. Песочницы и проверки безопасности кода нет. Ошибка загрузки показывается в строке плагина; исключение из работающего плагина прекращает его вызовы, чтобы приложение продолжало работать. Удаление или обновление выключает прежнюю версию.

## Публикация и сервер

Убрана политика запрета API и обфускации также из Python-сервера `server/plugin_audit.py` и панели. Приём, каталог и скачивание проверяют структуру пакета и целостность, без фильтрации действий кода. Для применения обновите `server/badges.py`, `server/plugin_audit.py` и `server/panel.py` на своём сервере. Эти исходники автоматически не развёрнуты.

Cloudflare Worker хранит бинарные `.ctt` в D1 (до 1 МиБ); для больших файлов можно использовать прямую ссылку GitHub Release в `public/plugins/catalog.json`. Публикация и удаление требуют прежних прав владельца/администратора магазина. Очередь ручного одобрения командных JSON-плагинов сохранена: это управление общим каталогом, не блокировка кода на устройстве. Настройка: [редактор](plugin-editor.md), [API](plugins.md).

Проверки: `tests/test_plugin_audit_runtime.py`, `tests/test_plugin_publication.py`, `tests/plugins-server.test.mjs`. Они проверяют допустимость прежних блокируемых API/обфускации и отказ повреждённым пакетам.
