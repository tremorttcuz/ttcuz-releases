# ttcuz Plugin Engine

Нативные Java/DEX-плагины устанавливаются в меню **ttcuz → Плагины**.
Установка, включение, настройки, перезагрузка, журнал ошибок и удаление — без
перезапуска приложения. Обновление сохраняет данные; при ошибке запуска новой
версии движок возвращает предыдущую рабочую версию.

Формат `.ttplugin` — ZIP с `manifest.json`, `classes.dex`, при необходимости
`classes2.dex` и далее, `assets/`, `lib/<abi>/` и `resources.apk`.
Загрузчик не использует список разрешённых авторов, подписи плагинов,
декларации возможностей или фильтрацию Java API. Плагин исполняется в процессе
TikTok с правами приложения, его файлами и сессией. Это доверенный нативный код,
не изолированный скрипт. Проверки корректности архива, путей, совместимости API
и обязательный для Android read-only DEX остаются.
