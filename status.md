## Опубликовано

Страница инструкций: <https://ttcuz.ttcuz1337.workers.dev/guide.html>. На том же бесплатном Cloudflare Worker работают `/health`, `/badges` и `/version`. Адреса руководства, публичного списка значков и проверки версии подключены к исходникам. Сервер `/version` автоматически читает последний стабильный GitHub Release из `tremorttcuz/ttcuz-releases` и выбирает вложение `ttcuz.apk`. Релиз с APK пока не опубликован, поэтому ссылка пустая. Опубликованы маршруты синхронизации `/v1/` с постоянным хранилищем D1 и проверкой кода в описании TikTok. Успешная проверка реального профиля и обмен между телефонами пока не проверены. Магазин плагинов отложен. Новые форматы: `.cuztx` и `.ctt`. Документация опубликована: https://github.com/tremorttcuz/ttcuz-releases.
