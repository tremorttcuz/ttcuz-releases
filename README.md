# ttcuz 0.6.8.13 — Google Icons

[Приватный репозиторий](https://github.com/tremorttcuz/ttcuz-private) — доступ только владельцу и приглашённым аккаунтам.

Исходники мода на базе TikTok 47.2.41. Текстурпаки и поддержка плагинов удалены из приложения. Движок и сборщик используют имя ttcuz; подпись рядом с заголовком убрана.

Нижняя навигация — островок MD3 с анимированным индикатором. [Проверка целостности](docs/integrity.md) блокирует подменённые APK; абсолютной защиты от изменения исходников нет.

Шрифты текста и эмодзи настраиваются независимо. Сохранены Apple MFFM Color Emoji, Twemoji 17.0.3, семифигурный MD3-индикатор загрузки, DownloadIsland, скачивание аудио, глаз под стрелкой «Назад», темы и настройки профиля. Встроенный музыкальный плеер удалён в предыдущих версиях.

[Изменения](CHANGELOG.md) · [Проверка версии 0.6.7.8](docs/release-0.6.7.8.md) · [Эмодзи](docs/emoji-fonts.md) · [Руководство](docs/ttcuz-guides.md) · [Лицензия](LICENSE) · [Сторонние компоненты](NOTICE.md)

Для сборки нужен официальный универсальный APK TikTok 47.2.41, JDK 17+ и Python 3. `python -m ttcuz путь/к/tiktok.apk --help` показывает параметры. Для защищённой сборки нужен явный `--keystore`, отдельный закрытый ключ целостности и переменные окружения из [инструкции](docs/integrity.md). Ключи не включаются в проект. Android SDK API 35 и остальные инструменты сборщик получает в `tools/`; APK и ключи в архив исходников не включены. Для обновления установленного приложения используйте прежний ключ подписи.

Проверки: `python -m unittest discover -s tests`; сервер: `node --test tests/*.test.mjs`.

Папка [plugins/](plugins/README.md) содержит сохранённые исходники прежней подсистемы, которые не включаются в APK. Серверные файлы магазина остаются в `server/`; этот выпуск не развёртывает сервер.

Работа на физическом телефоне пока не проверена.

## Документация

- **Плагины: написать и собрать на ПК и в Termux** — [docs/plugins-guide.md](docs/plugins-guide.md) (короткая версия для телефона: [docs/termux-plugin.md](docs/termux-plugin.md)).
- Сборка APK: `python3 -m ttcuz путь/к/tiktok-47.2.41.apk --keystore ключ.jks` (`--help` — все параметры). Кеш dex лежит в `ttcuzcache/` (`--cache` меняет папку). Задачи распределяются по свободной памяти, поэтому на машине с 8+ ГБ dex обрабатываются параллельно.
- Liquid Glass, островок и демо: [docs/demo/navigation-island-demo.html](docs/demo/navigation-island-demo.html); изменения — [CHANGELOG-short.md](CHANGELOG-short.md).
- Ключи подписи, APK TikTok и скачанные инструменты в репозиторий не входят.
