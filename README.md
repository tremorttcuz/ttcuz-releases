# ttcuz — исходный код

Android-мод для TikTok 47.2.41, собственный движок плагинов и сервер Cloudflare.
Исходники находятся прямо в репозитории, распаковывать ZIP для чтения не нужно.
Текущие исходники — 0.6.8.9; последний собранный APK — 0.6.8.8. Изменения
исходников пока не вошли в APK.

## Сборка

Нужны Python 3.9+, JDK 17+ и официальный универсальный APK TikTok 47.2.41.
Инструменты Android сохраняются сборщиком в `tools/`. Ключи подписи, секреты,
исходный APK, результаты сборок и кэш в репозиторий не включаются.

```sh
python -m ttcuz --help
python -m ttcuz path/to/tiktok.apk -o outputs/ttcuz.apk --work .work/build --tools tools
```

Перед реальной сборкой настройте ключи по [инструкции](docs/integrity.md).
Для обновления установленного приложения обязательно нужен прежний сертификат.
Пример выше не содержит пользовательских закрытых ключей.

### Повторные сборки и DEX-кэш

Кэш по умолчанию включён. `TTCUZ_CACHE` задаёт его каталог, `TTCUZ_WORKERS`
ограничивает число одновременных DEX-задач, `TTCUZ_HEAP` — память Java-задачи.
Неизменённые входные DEX и применимые правила повторно используют готовый
результат. Изменившиеся правила и неизвестные изменения безопасно пересчитываются.
`TTCUZ_NO_CACHE=1` отключает кэш. `TTCUZ_CACHE_BASELINE` может указывать на
предыдущий архив исходников для распознавания прежних правил; его код не запускается.
Сам кэш и предыдущие результаты не публикуются как исходный код.

## Проверки

```sh
python -m unittest discover -s tests
node --test tests/*.test.mjs
```

Часть проверок требует JDK. Компиляция и тесты не заменяют проверку интерфейса
и реальной отправки комментариев на телефоне. Ограничения API TikTok могут
зависеть от аккаунта, региона и сервера.
