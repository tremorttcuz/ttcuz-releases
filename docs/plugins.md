# Плагины ttcuz

Руководство текущих исходников. Для новых окон нужен APK, собранный из этих
исходников: обновление сервера само по себе не меняет установленный мод.

## Магазин и редактор внутри мода

Откройте **Настройки мода → Плагины**:

- **Магазин плагинов** — нативный каталог и установка внутри приложения.
- **Создать плагин** — нативный редактор Java с черновиком.
- **Установить плагин** — импорт локального `.ctt` через проводник Android.
- Установленные плагины: включение, настройки, перезагрузка, удаление.
- **Модерация магазина** — административная страница владельца. Она пока
  открывается в браузере с краткосрочным сеансом.

Каталог показывает название, версию, описание и отметку проверки; скрывает
пакеты для другой версии TikTok. Перед установкой SHA-256 скачанного пакета
сверяется с каталогом. Ошибку загрузки можно повторить.

## Формат `.ctt`

Это ZIP-контейнер нативного плагина. Старые нативные `.ttplugin` продолжают
импортироваться; новые пакеты создаются как `.ctt`. Старые Python-плагины
и декларативные пакеты другого движка автоматически совместимыми не становятся.

```text
manifest.json
classes.dex
classes2.dex                 # необязательно, multidex
assets/                     # необязательно
lib/arm64-v8a/               # необязательно
resources.apk               # необязательно
```

`manifest.json` и первый DEX лежат в корне, без дополнительной общей папки.
Пути за пределы архива, дубликаты, повреждённые DEX и несовместимый API
отклоняются. Предел распаковки — 512 МиБ и 16384 записи.

```json
{
  "id": "ttcuz.my-plugin",
  "name": "Мой плагин",
  "version": "1.0.0",
  "author": "tremor",
  "description": "Краткое назначение",
  "entry": "ttcuz.plugins.MyPlugin",
  "api": 1,
  "tiktok": "47.2.41"
}
```

`id` постоянный: установка того же ID обновляет пакет. `entry` — полное имя
открытого класса-наследника `TtcuzPlugin` с открытым конструктором без параметров.
`api` должен совпадать с API движка. Необязательный `tiktok` ограничивает
пакет конкретной версией; без него совместимость проверяет автор плагина.

## Работа в редакторе

1. Заполните название, ID, автора, версию и главный класс.
2. Измените код. Переключатель файлов выбирает текущий Java-файл.
3. «Добавить Java-файл» создаёт путь вида `java/ttcuz/plugins/Helper.java`.
4. Черновик сохраняется после паузы ввода. На аккаунт хранится один проект;
   черновики разных аккаунтов разделены.
5. «Экспорт исходников ZIP» открывает системное окно сохранения.
6. «Отправить на проверку» передаёт исходники в очередь и показывает ID заявки.
   Ошибка отправки не удаляет черновик.

До 32 Java-файлов, до 240000 символов в файле и до 1 МБ JSON-проекта.
Дополнительные серверные ограничения проверяются при отправке.
Экспортированный ZIP содержит исходники, **не готовый DEX**. Компилятор Java/D8
в приложение не встроен. Редактор не предоставляет отладчик, автодополнение
или импорт произвольного Gradle-проекта.

## Сборка `.ctt` на компьютере

Нужны Python, JDK, `android.jar`, `r8.jar` и SDK этой версии мода
(`*-plugin-sdk.jar`, выдаваемый сборщиком мода).

```text
my-plugin/
  manifest.json
  java/ttcuz/plugins/MyPlugin.java
  assets/                    # необязательно
```

Из корня репозитория:

```sh
python -m ttcuz.plugin ./my-plugin --sdk ttcuz-plugin-sdk.jar --android tools/android.jar --r8 tools/r8.jar -o my-plugin.ctt
```

Команда компилирует Java, создаёт DEX и упаковывает `.ctt`; APK и ключ его
подписи не требуются. `--classpath` добавляет JAR только для компиляции,
`--include` также включает зависимость в DEX. Не включайте классы SDK
и штатные классы TikTok в собственный пакет.

## Пример и API 1

```java
package ttcuz.plugins;
import cat.ttcuz.framework.plugin.TtcuzPlugin;
import cat.ttcuz.framework.plugin.PluginSettings;

public class MyPlugin extends TtcuzPlugin {
    @Override public void onSettings(PluginSettings s) {
        s.toggle("enabled", "Мой эффект", true)
            .slider("strength", "Сила", 0, 100, 50)
            .action("Проверить", () -> ttcuz().toast("Работает"));
    }
}
```

`PluginSettings`: `text`, `action`, `toggle`, `choice`, `slider`, `view`.
Обычные значения хранятся в `ttcuz().prefs()`; аккаунтные — через `accountPrefs()`.
Для собственного окна переопределите `onOpenSettings(Activity)` и верните `true`.

| Обработчики `TtcuzPlugin` | Назначение |
| --- | --- |
| `onLoad()` | Подготовка в потоке загрузчика |
| `onStart()`, `onStop()` | Запуск/остановка в главном потоке |
| `onActivityCreated/Resumed/Paused/Destroyed(Activity)` | Жизненный цикл экранов |
| `onAccountChanged(uid)` | Смена аккаунта |
| `onPreferenceChanged(scope, key)` | Изменение настроек |
| `onSettings`, `onOpenSettings` | Настройки плагина |
| `onView(View)` | Обработка View при привязке |
| `onColour`, `onText`, `onNickname`, `onRegion`, `onFeed` | Преобразования данных |
| `onEvent(name, payload)` | События между плагинами |

| Методы `PluginContext` через `ttcuz()` | Назначение |
| --- | --- |
| `app`, `screen`, `hostLoader` | Контекст, Activity, загрузчик приложения |
| `type`, `method`, `field` | Классы и reflection |
| `prefs`, `accountPrefs` | Общие/аккаунтные настройки |
| `bundle`, `data` | Код/ресурсы пакета и отдельные данные |
| `accountId`, `accent` | Текущий UID и акцент |
| `ui`, `later`, `away` | Выполнение задач |
| `log`, `toast`, `emit` | Журнал, сообщение и событие |

[Подробные правила вызовов и сигнатуры](plugin-engine.md).
Преобразования выполняются в исходном потоке: не делайте там сетевые запросы
и тяжёлые обходы. В `onView` избегайте дублирования элементов. В `onStop`
освобождайте свои слушатели, потоки и окна. Плагин выполняется в процессе
приложения с его правами; отдельной песочницы возможностей нет. SDK
не предоставляет универсальный перехват любого ART-метода и не отменяет
ограничения Android. Native crash и бесконечный цикл нельзя обезвредить `try/catch`.

## Проверка, публикация и владелец

`POST /plugins/native/submit` принимает читаемые Java-исходники. Заявка
сохраняется до обращения к внешним сервисам, уведомление идёт владельцу
в Discord DM. Разбор ИИ включается при настроенном серверном ключе Gemini.
Ключи Google/Discord хранятся в секретах сервера, не в APK или репозитории.
Выявленная обфускация и скрытая загрузка кода препятствуют отправке на проверку.
Статический анализ и ИИ не гарантируют безопасность; решение принимает владелец.

Владелец принимает/отклоняет заявки, назначает марки авторам, публикует
и удаляет пакеты. Отметка проверки — ручная аттестация владельца.
Пакет в магазине ограничен 1 МиБ; локальный импорт имеет отдельные лимиты выше.

Текущий аккаунт считывается из службы TikTok при открытии настроек.
Сервер проверяет UID владельца, прежнее подтверждение и ключ устройства.
Доверенное устройство автоматически восстанавливает доступ после смены
локального токена, сохраняя подтверждение. Один ник или введённый UID
не дают права администратора. При утрате всех доверенных ключей остаётся
подтверждение управления профилем. Сеанс веб-модерации живёт 10 минут;
постоянный токен не передаётся в URL.

Каталог: `GET /plugins/catalog.json`. Пакеты:
`/plugins/files/{id}/archive.ctt`. Старые ссылки `archive.ttplugin` сохраняются.

## Частые ошибки

- **Нет `classes.dex`:** выбран исходный ZIP; сначала соберите `.ctt`.
- **Нет плагина в магазине:** проверьте публикацию и совместимость TikTok.
- **Не совпал SHA-256:** снова откройте магазин; пакет мог быть обновлён.
- **HTTP 429 / Cloudflare 1027:** внешний лимит сервера; повторное подтверждение
  профиля его не снимает. Дождитесь снятия ограничения Cloudflare.
- **Не открывается модерация:** вернитесь в аккаунт владельца и повторите;
  восстановление доверенного устройства выполняется автоматически.
- **Ошибка обработчика:** экземпляр останавливается, подробности попадают
  в журнал; исправьте код и перезагрузите плагин.

Удаление сохраняет настройки и данные плагина. При неудачной замене пакета
движок пытается вернуть предыдущий код; уже выполненные действия самого
плагина такой откат отменить не может.

## Где читать исходники

- `inject/java/cat/ttcuz/framework/PluginWorkbench.java` — окна магазина/редактора.
- `PluginEngine.java`, `PluginPackage.java`, `plugin/` — движок, контейнер и API.
- `ttcuz/plugin.py` — сборка `.ctt` на компьютере.
- `server/cloudflare/plugins.mjs`, `native-plugins.mjs` — каталог и модерация.
