# Исправления исходников: активность и фон комментариев

APK не собирался. Версия не менялась: это исправление исходников 0.6.8.5.

- «Прочитать всё»: запрос активности повторяет параметры MultiViewModel из официального TikTok 47.2.41: experiment_params, additional_group_list, business_params и need_mark_read=true. Используется родной IO scheduler. Раньше служебные параметры отсутствовали, а список групп составлялся из другого источника.
- Личные сообщения и активность обрабатываются независимо. Сообщение о результате различает полный и частичный успех; причины ошибок записываются вместе с цепочкой исключений.
- Счётчики активности и подписок обновляются через родной менеджер только после успешного ответа API. Учитываются также категории, имеющие счётчики без записи в таблице атрибутов.
- Настройки приватности не отключаются при выполнении действия.
- Фон комментариев не задаёт высоту обычного окна. В настройках фона добавлены варианты «Заполнить с обрезкой», «Показать целиком» и «Растянуть» для видео и GIF.
- Растяжение теперь выбрано по умолчанию для существующих установок и новых профилей. Видео с любым соотношением сторон независимо масштабируется по ширине и высоте до границ обычного окна комментариев; настройка остаётся доступной для смены режима.
- Семантические цвета текста и значков разрешаются штатным Tux resolver, как в исходном приложении; исправлена причина повторяющихся Resources$NotFoundException из журнала.

Проверки: Java компилируется против Android и текущих классов проекта; runtime-тесты проверяют параметры запроса, отказ до подтверждения сервера, частичные результаты, размер фона и масштабирование. Реального устройства и авторизованного запроса к TikTok в этой среде нет: подтверждение поведения сервера и приложения на телефоне остаётся необходимым.
