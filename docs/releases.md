# Публикация обновлений ttcuz

Репозиторий APK и документации: https://github.com/tremorttcuz/ttcuz-releases

1. Соберите готовый мод, увеличив `VERSION` и Android `versionCode`. Сохраняйте прежний package name и ключ подписи: иначе Android не установит APK поверх предыдущего.
2. Переименуйте APK в `ttcuz.apk` или `ttcuz-<версия>.apk` (например, `ttcuz-0.6.8.1.apk`).
3. В репозитории откройте Releases → Draft a new release. Создайте новый тег версии, добавьте соответствующие пункты из `CHANGELOG.md`, прикрепите только APK, затем нажмите Publish release. Не отмечайте Draft или Pre-release для общего обновления.
4. Проверьте https://ttcuz.daniilsolovatulin.workers.dev/version — там появятся версия, прямая ссылка на APK и описание из релиза. Кеш сервера — до пяти минут.

Настройки сервера после каждого релиза редактировать не нужно. Он читает последний опубликованный стабильный релиз этого репозитория. Релиз принимается с файлом `ttcuz.apk` или `ttcuz-<версия>.apk`.

Мод проверяет сервер при старте и затем каждые пять минут, пока процесс приложения работает. При новой версии появляется окно с описанием изменений и кнопкой скачивания. Уведомление в системной шторке при закрытом приложении пока не реализовано. Скачивание запускается после нажатия пользователем, установку подтверждает Android. В настройках можно отключить напоминания.

Загрузчик поддерживает до пяти HTTPS-перенаправлений, нужных для файлов GitHub Releases. После публикации нового релиза проверьте `/version`: сервер должен отдавать новую версию и ссылку на `ttcuz.apk`. Полную загрузку и установку следует подтвердить на телефоне.

## Тестовые исходники 0.6.7.8

Тестовая ветка — `codex/testing-v0.6.7.8`, исходники и ZIP — `testing/v0.6.7.8/`. Стабильный релиз и адрес обновления не меняются. Исходники нового выпуска размещаются только в приватном репозитории https://github.com/tremorttcuz/ttcuz-private. Для доступа требуется приглашение; одна ссылка доступа не даёт. Оригинальные изменения ttcuz защищены закрытой лицензией, сторонние материалы — их собственными условиями.
