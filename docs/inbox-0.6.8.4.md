# 0.6.8.4 — изменения исходников

APK не собирался и не публиковался. База — официальный TikTok 47.2.41.

## Изменения

- `Dim.chatOpened/chatClosed` получают состояние из жизненного цикла `BaseChatRootFragment`, а не из текста, подсказки или положения поля ввода. Открытый чат запрещает затемнение и отрисовку глаза; закрытие снимает запрет.
- `Net.postFont` допускает JSON до 1 500 000 символов для допустимого TTF/OTF до 1 МиБ. Прежний общий лимит 65 536 символов отбрасывал многие шрифты ещё до отправки. Для обычных запросов лимит сохранён. `CloudProfileProvider` использует новый путь только для загрузки шрифта.
- `NicknameFont.apply` убирает конкурирующие `TypefaceSpan` на участке ника. Шрифт владельца применяется и при измерении, и при рисовании, сохраняя жирность/курсив; шрифт приложения читателя его не заменяет. Для распространения оформления по-прежнему требуется включённая публикация оформления и доступный сервер. Это поддержка в ttcuz, а не изменение официальных клиентов TikTok.
- В родное меню «Инструменты сообщений» добавлена строка «Прочитать все» с родной иконкой `icon_bubble_right_tick`. Чаты выбираются запросом к базе аккаунта, без лимита видимой страницы, с `includeStranger=true`; выбираются только непрочитанные. Используется родной `batchMarkRead`. Для активности отправляется авторизованный `need_mark_read=true` через `MultiApiManager`, после успешного ответа обновляются локальные счётчики. Ошибка/таймаут не объявляются успехом. Защита от повторного запуска и смены аккаунта включена.
- `InboxFilter` меняет только шейдер штатного градиента возле кнопки фильтров. Цвет берётся из непрозрачной подложки панели/предков, учитывается RTL; новый шейдер создаётся при изменении геометрии/цвета или сбросе самим TikTok. Наблюдатель снимается при отсоединении View.

## Точечные правки APK

Все сигнатуры и поля сверены с оригинальным APK, а патчи проверены на копиях оригинальных smali:

| Класс | Место |
| --- | --- |
| `com.ss.android.ugc.aweme.im.sdk.chat.ui.singleactivity.BaseChatRootFragment` | `onResume`, `onStop`, `onDestroy` |
| `ft6.AbS21S0300000_11` | `LIZ$1`: список строк родного меню; также обход быстрого выполнения единственного стандартного пункта |
| `X.0TD8` | Конструктор панели фильтров, `LLJLLIL` — градиент `X.0DdO`, `LL` — его Paint |

Проверено: 1 вход в чат, 2 выхода, 1 меню, 1 градиент. Повторный запуск патча не дублирует вызовы. Патч включён в выбор DEX и fingerprint кэша; будущая сборка требует наличия всех этих вставок.

Чтение переписок: `X.06WS.LIZIZ` → `X.06Wp.LJIIJ(X.06kl)` → `X.06Yb.LIZIZ`; запрос с пустым стандартным `X.0Rr5`, `SORT_ORDER_DESC`, limit=-1, cursor=null, includeStranger=true. Метод `LIZLLL` не используется: он возвращает только группы. Отметка: `LJIJI(List, X.0Tf0)`. Проверка состояния читает актуальные объекты через `LIZ(conversationId)`.

Активность: `X.1Gjy.LJJJJ` даёт все группы; `MultiApiManager$API.LIZIZ` обращается к `/tiktok/notice/entrance/list/v1/`. После успешного `status_code=0` вызывается `X.1Gjy.LJFF`. Счётчики не обнуляются вместо сетевого запроса.

## Проверки и ограничения

- Весь Java-код проходит javac с Android API 35 и описаниями классов TikTok. D8, сборка DEX, APK и подпись не запускались.
- Выполнены тесты антивыгорания, клавиатуры/длинного сообщения и возврата на ленту; шрифтов, отправки 1 МиБ и независимости от семейства читателя; градиента, RTL, кэширования шейдера и снятия наблюдателя; выборки личных/групповых чатов и запросов, замены объектов SDK и смены аккаунта; идемпотентности патчей, DEX-кэша и приватности. Серверные тесты валидации и хранения шрифтов проходят локально.
- Телефон/эмулятор не подключён: проверка родного меню и сетевых операций на устройстве остаётся обязательной перед релизом.
- Во время проверки действующий `ttcuz.daniilsolovatulin.workers.dev` отвечал HTML-ошибкой Cloudflare HTTP 429 (temporarily rate limited), включая health и endpoint шрифтов. Код клиента не снимает это ограничение сервера. Поэтому фактическое получение чужого шрифта через рабочее облако пока не подтверждено. Сервер в этой задаче не развёртывался.
