# Перетаскивание индикатора вкладки

Индикатор выбранной вкладки можно зажать на 0,3 с, перетащить по вкладкам и отпустить: он сядет на ближайшую вкладку, а TikTok получит обычное касание по ней.

## Поведение

- До срабатывания удержания все касания идут в TikTok как раньше; сдвиг больше порога отменяет удержание.
- При удержании индикатор «поднимается»: растёт в ширину (и по высоте, если над ним есть место), светлеет, при быстром движении растягивается по ходу. Пружины Material 3 Expressive: положение 520/30, подъём 520/26.
- Индикатор всегда полностью скруглён и остаётся внутри островка: 6 dp от боковых краёв, высота ограничена свободным местом над ним (в Java `room`).
- Кнопку «+» индикатор не выбирает: ближайшая вкладка считается только среди Главная, Друзья, Входящие, Профиль; индикатор плавно идёт за пальцем без скачков.
- Смена ближайшей вкладки даёт короткую вибрацию, отпускание — ещё одну.
- Отмена жеста (`ACTION_CANCEL` / `pointercancel`, потеря фокуса) возвращает индикатор на прежнюю вкладку и не выбирает новую.
- При отключённых анимациях индикатор двигается без пружин.

## Файлы

- `inject/java/cat/ttcuz/framework/IslandTouch.java` — распознавание удержания и перехват жеста окном.
- `inject/java/cat/ttcuz/framework/NavigationIsland.java` — `beginDrag`, `dragTo`, `drop`, пружины и рисование.
- `docs/demo/island-demo.html` — демо в браузере (то же поведение).
- `tests/test_navigation_island_runtime.py` — Java-проверка, включая границы у краёв островка.
- `tests/test_island_demo_browser.py` — проверка демо в Chromium (пропускается без Playwright).
