# Островок и переходы — 11 октября 2026

Этот архив содержит исходники поверх предыдущей версии с исправленной проверкой целостности. Новый APK не собирался и приложение на устройстве не запускалось. Старые отчёты в `verification` относятся к прежним версиям; текущий результат — `verification/island-optimization/checks.json`.

Изменения:

- Удалена дополнительная цветная подложка кнопки «+». Сама кнопка создания видео остаётся штатной.
- Индикатор вкладки выровнен по одной горизонтали. Его ширина учитывает узкую панель; отрисовка ограничена закруглёнными границами островка. Обычный переход сокращён с 340 до 180 мс и больше не растягивается и не подпрыгивает. Области нажатия, счётчики и расположение штатных кнопок не меняются.
- Завершившаяся анимация больше не блокирует дальнейшие изменения размеров. Островок останавливает задачи при паузе и потере фокуса, освобождает состояние при закрытии окна и не перерисовывается бесконечно при неподвижном удержании. Поиск его элементов повторяется при изменении структуры.
- Настройки оформления профиля не читаются перед каждым кадром: изменения объединяются в отложенную задачу с интервалом от 300 мс. Повторный полный пересчёт затемнения при непрерывных изменениях макета ограничен интервалом 120 мс; окончательное состояние сохраняется, показ кадров не блокируется.

Проверены 12 тестов, включая быстрые переключения, узкую панель, перетаскивание, остановку анимаций, пакетирование обновлений, затемнение и жизненный цикл окон. Это проверки логики на JVM с имитацией Android; они не измеряют FPS и не заменяют проверку на телефоне.

Исправление проверки целостности из предыдущего архива сохранено без изменений.
