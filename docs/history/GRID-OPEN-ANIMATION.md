# Открытие видео из сетки профиля

Добавлено раскрытие окна проигрывателя из нажатой карточки. Работает с зарегистрированными сетками вкладок профиля: видео, приватные публикации, репосты, избранное и понравившееся. Для штатной сетки достаточно даже одной карточки. Исходная точка и размер берутся из видимой части карточки, с учётом обрезки при прокрутке и положения окна на экране.

Переход использует штатный `ActivityOptions.makeScaleUpAnimation`. Android анимирует окно; мод не создаёт снимки карточек, размытие или дополнительный видеоплеер, не задерживает запуск для анимации и не пересчитывает сетку на каждом её кадре. Продолжительность и форма перехода зависят от Android и оболочки телефона. Это приблизительное раскрытие по примеру, без отдельной анимации закрытия.

Нажатия и прокрутка остаются штатными: обработчик только наблюдает события окна. Прокрутка, второй палец, отмена жеста, долгое нажатие, скрытая карточка и уход приложения в фон отменяют подготовленный переход. Отключение анимаций в системе учитывается. Состояние хранится со слабыми ссылками и действует не более 700 мс после отпускания пальца.

Подключение проверено на настоящем `ActivityRoute.openComponent` из TikTok 47.2.41, непосредственно перед чтением параметров открытия. Изменяется только запуск `DetailActivity` или `PostModeDetailActivity` внутри приложения. Существующие переходы и запуски с ожиданием результата сохраняются: для них дополнительное раскрытие не применяется. При ошибке подготовки TikTok продолжает штатный запуск. Переходы внутри одного окна и прямые запуски в обход этого роутера остаются штатными.

Кэш будущей сборки учитывает новый обработчик; старый совместимый кэш роутера больше не используется. Проверка обязательных подключений не позволит пропустить новый обработчик молча. Предыдущие исправления островка и проверки целостности сохранены.

Проверено 12 автоматическими тестами, включая настоящие Java-классы с имитацией Android, передачу штатных событий нажатия, видимые границы карточки, вкладки, отмену жестов, жизненный цикл, однократный запуск и выбор кэша. Настоящий код роутера проверен на точечность изменения и повторное применение без дублирования. Результаты: `verification/grid-open/checks.json`.

APK не собирался, приложение на телефоне не запускалось. Плавность и FPS на устройстве пока не измерены. Для проверки: открыть карточки всех доступных вкладок профиля, включая чужой профиль; повторить с прокруткой и частично скрытой карточкой; проверить долгое нажатие, быстрое открытие/возврат, свайп между вкладками и отключённые системные анимации.
