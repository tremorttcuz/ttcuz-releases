# Исправление проверки в 0.6.7.8 smooth

- Экран проверки больше не вызывает finish() у исходных Activity TikTok и не запускает их Intent повторно после проверки. Он открывается поверх исходной задачи и закрывает только себя.
- Успешная проверка сохраняется между запусками той же установленной сборки. Обновление APK сбрасывает результат; ошибки и подмена не кешируются.
- Ошибка кеша не блокирует успешно проверенный APK. Ошибки загрузки классов в проверяющем потоке показывают повторяемую ошибку вместо необработанного исключения.
- Сборка использует проверенные 53 нативных DEX предыдущего APK при полном совпадении правил обработки. Код мода, ресурсы, печать целостности и подпись собираются заново из предоставленного ZIP.

Проверка на реальном телефоне не выполнена. Логи и результаты текущей сборки находятся в verification/integrity-fix/.
