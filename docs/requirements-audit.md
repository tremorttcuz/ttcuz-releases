# Сверка требований — 13 октября 2026

Проверена исходная версия ttcuz 0.6.8.2 для официального TikTok 47.2.41.
APK не собирался. «Проверено» ниже означает проверку исходников, автоматических
сценариев и, где указано, классов официального APK. Подключённого телефона нет:
проверки поведения на настоящем устройстве и измерения частоты кадров не выполнены.

## Исправлено при этой повторной проверке

1. После быстрого закрытия и открытия GIF старый результат декодирования мог
   оставить новое окно пустым или сбросить состояние новой загрузки. Результат
   принимается только своим поколением окна; Android GIF явно зациклен.
2. Жест назад со страницы фона комментариев возвращал в другой раздел, чем кнопка.
3. Закрытие одного окна комментариев могло очистить фон другого. Пауза,
   возобновление и очистка теперь привязаны к конкретному фрагменту; повторное
   подключение очищенного окна также проверено.
4. При неудачной записи шрифта Android мог обновить настройки в памяти, а файл
   уже откатился. Теперь откатываются файл, выбор и хеш; ограничен кеш и повторный
   запуск импорта.
5. Тест лайков переведён на настоящий `NativeRead`, а тест записи настроек
   воспроизводит изменение памяти при `SharedPreferences.commit(false)`.
