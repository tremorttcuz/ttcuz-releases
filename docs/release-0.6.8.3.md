# 0.6.8.3

Исправления для TikTok 47.2.41.

- Фон комментариев: очищается также нативная подложка списка 0x7f0a4ce4. Если TikTok восстанавливает её после загрузки или смены темы, перед отрисовкой фон снова убирается. Обход ограничен известными контейнерами, без перебора строк и без изменения кнопок/фото. При отключении и уничтожении окна наблюдатель удаляется, последняя нативная подложка возвращается.
- Превью иконок: единый размер 64 dp, скругление 18 dp, центрирование и отдельный отступ для обводки выбранной иконки.
- Поддержка ТТЮ: присланный прозрачный PNG включён в assets/ttcuz/tty-supporter.png. Публичный список задаёт только членство; все поддержавшие используют одну встроенную картинку и подпись «Поддержал ТТЮ».
- Подпись APK и сертификат в защитном списке создаются одним прежним ключом Android; переподписывать готовый APK другим ключом без обновления защитного списка нельзя.

Проверки: сценарий импорта, восстановления подложки, отключения и жизненного цикла; тесты muted-видео и публичного списка ТТЮ; проверки нативных хуков. Фактическое воспроизведение на телефоне нужно проверить после установки.
