# Проверка 0.6.8.7

## Выполнено

- Исправлены пути градиента подготовленного двойного сердечка, неизменного основного цвета и лайков комментариев.
- Собственный нативный ttcuz Plugin API 1, SDK JAR, сборщик и примеры. Прежний движок вынесен из распространяемых исходников в локальный архив.
- Установка, обновление с откатом, перезагрузка, выключение, удаление с сохранением данных. Java-ошибки обработчиков останавливают экземпляр плагина.
- Кнопка магазина на главном экране настроек, собственная SVG-иконка, редактор Java-проекта, очередь исходников и панель владельца.
- Публикация и удаление пакетов, марки авторов, принятие/отклонение исходников, Gemini и Discord DM. Постоянный ключ владельца не нужен для входа из мода: временный сеанс на 10 минут.
- Причина вылета берётся из цепочки Throwable, место — из исходного исключения. Запись отчёта синхронизируется на диск, затем переименовывается; повреждённый отчёт не блокирует отправку следующих. Очередь повторно отправляется при возврате приложения.
- Миграция D1 применена, Worker опубликован; Gemini API key хранится в Worker secret. Реальные GET магазина/редактора/health вернули 200 через Node fetch.

## Проверки и пределы

22 выбранные проверки Python/JVM и 23 проверки Node прошли. Полная Java-компиляция прошла; пример Hello и исходный шаблон веб-редактора собраны через реальный D8.

Движок тестировался в JVM-модели Android. Телефон не подключён; внешность и работа DEX на устройстве не подтверждены. Встроенный браузер проверки не запустился из-за ошибки локального инструмента.

Google подтвердил доступ к модели gemini-3.5-flash-lite. Пробный generateContent получил 503, повторная попытка — таймаут. Не заявляем успешный живой разбор ИИ: сервер сохраняет заявку и позволяет повторить анализ. DM-транспорт проверен тестами; тестовые заявки в личные сообщения не отправлялись.

Обфускация проверяется по выявляемым признакам, её произвольную форму гарантированно обнаружить невозможно. ИИ не утверждает абсолютную безопасность. Значок «проверен» выдаёт владелец, подтверждая собственную сборку из принятых исходников; автоматического сравнения исходников с чужим DEX нет. Лимит серверного пакета — 1 МБ.

Старые плагины другого SDK требуют переноса. Прямой доступ к Android не обходит ограничения ОС и не позволяет гарантированно остановить произвольный native crash. Java uncaught exceptions фиксируются при включённом согласии на отчёты; SIGKILL, потеря питания, полный диск и часть native crashes не гарантируют отчёт.
