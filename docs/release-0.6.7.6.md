# 0.6.7.6 — эмодзи

Добавлен Apple MFFM Color Emoji 2.051 MFFM, обновлён Twemoji до 17.0.3 и исправлено неполное применение выбранного шрифта. Подробнее: [эмодзи](emoji-fonts.md).

Сохранены все изменения 0.6.7.5: MD3 вместо найденных точек загрузки, удаление музыкального плеера, DownloadIsland, глаз под стрелкой, лимиты, кнопки и исправление смены иконки.

- 245 автоматических Python/Java-проверок — OK. Включены все 5225 распознаваемых последовательностей, флаги, модификаторы кожи, ZWJ, keycap, ввод текста, EmojiCompat, смена шрифта, системный сброс, сохранность ссылок и стикеров, повторное применение без перезаписи текста.
- HarfBuzz проверил все 3944 полные формы Unicode Emoji 17 на обновлённом Twemoji 17.0.3: по одному видимому глифу на форму, без пропусков.
- Та же проверка присланного Apple MFFM Color Emoji прошла для всех 3944 полных форм. Примеры пикселей из обоих шрифтов: `verification/0.6.7.6/emoji-preview.png`.
- Весь код мода и ресурсы пересобраны с Android SDK API 35. Нативные правила не менялись: все 53 нативных DEX побайтово сохранены из проверенной 0.6.7.5, прежний DEX мода исключён. Это инкрементальная сборка.
- Все 218 требуемых патчеру методов определены. Новый EmojiText и его методы измерения/отрисовки включены в DEX 035, minSdk 23. Android versionCode 2030709416.
- APK: CRC, zipalign, подписи v1/v2/v3 и прежний сертификат проверены. Присланный файл в APK побайтово совпадает с оригиналом; Noto/Blobmoji и 15 ресурсов MD3 сохранены.
- Подробные логи и контрольные суммы: `verification/0.6.7.6/`.

Физический телефон не подключён. Нужно проверить эмодзи в комментариях, чате, профиле, поиске, вводе и настройках, смену шрифта и возврат к системным эмодзи.
