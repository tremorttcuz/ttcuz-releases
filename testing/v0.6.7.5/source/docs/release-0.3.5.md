## 0.3.5 — 5 октября 2026

- Репосты друзей с нативными данными upvote больше не удаляются фильтром карточек по типу и фильтром историй. Явная блокировка автора сохраняется. Мод не создаёт отсутствующие на сервере TikTok репосты.
- Добавлена автоматическая загрузка взаимных друзей через штатный подписанный запрос TikTok 47.2.41, с переходом по страницам. Ручное открытие списка TikTok не требуется.
- В списке друзей мода добавлены круглые аватарки, загрузка в фоне, два потока и ограниченный кеш уменьшенных изображений. Открытый список обновляется при поступлении данных.
- Избранные стикеры запрашиваются автоматически при входе и обновлении библиотеки. Повторные запросы ограничены; при переключении аккаунта старые результаты не принимаются. Нажатие стикера для продления сохраняет его ID, без копирования в буфер обмена.
- Добавлен переключатель «Отчёты о сбоях» в диагностике. Отправка выключена по умолчанию. Сохраняется технический стек Java-сбоя, версия мода, версия Android и время; тексты исключений, аккаунт, сообщения и журналы не включаются.
- До пяти отчётов сохраняются локально. Отправка выполняется при следующем запуске, в фоне; файл удаляется только после подтверждения сервера. Выключение отправки очищает локальную очередь.
- Подготовлены серверный приём отчётов, защита размера и частоты, хранение до 30 дней и закрытое чтение для администратора. Telegram-бот отложен по запросу пользователя.
- Защищены запуск синхронизации, обработчик отчётов, пустые стикеры и обратные вызовы загрузки миниатюр. Сбой сохранения отчёта не подавляет штатный обработчик TikTok.

Проверено: прежние 175 автоматических тестов и 3 новые проверки выполнения Java-кода, компиляция DEX, 22 серверных теста профилей и проверки маршрута отчётов. Новые проверки покрывают пагинацию и асинхронный ответ, смену аккаунта, фильтр социальных репостов и передачу сбоя штатному обработчику. На телефоне не проверено.

Ограничения: архив содержит исходный проект, не APK. Для отправки отчётов необходимо обновить Cloudflare Worker и применить миграцию базы. Нативные падения C/C++, ANR и принудительное завершение Android этим Java-обработчиком не собираются. Автопродление по-прежнему работает только при включённой функции и обнаруженных чатах; список взаимных друзей не превращается в список адресатов для автоматической рассылки. Источник данных репостов, друзей и избранных остаётся TikTok.
