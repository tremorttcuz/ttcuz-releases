# Комментарии к офлайн-видео

В штатном меню «Видео офлайн» есть пункты «Сохранять комментарии» и «Сохранённые комментарии». Сохранение выключено по умолчанию. Включите его перед следующей загрузкой видео и выберите 5, 10 либо своё количество от 1 до 1000.

Большее количество увеличивает время загрузки и расход места. TikTok может вернуть меньше комментариев: например, если их мало, они закрыты или недоступны аккаунту. Запрашивается штатный список TikTok; из полученных комментариев первыми сохраняются комментарии с большим числом лайков. Это не обещание глобального рейтинга всех комментариев ролика.

Загрузка видео не ждёт комментарии. Два фоновых работника сохраняют их после штатного события успешного кэширования видео. Повторные события одного видео объединяются. Готовый архив повторно используется в течение суток, если выбранное количество не менялось. Ошибка комментариев не отменяет загрузку видео.

Архив `offline-comments-<account>-<video-id>.zip` хранится в приватной папке приложения `files/margyt`. Связь с видео — его ID и имя видеофайла в метаданных. ZIP содержит `comments.json` и читаемый `comments.txt`, не содержит самого видео, токенов и cookie. В JSON записываются автор, ник, текст, дата и число лайков на момент загрузки. Картинки, вложенные ответы и аватары не скачиваются.

В офлайн-плеере нажмите «Сохранённые комментарии», чтобы открыть архив текущего видео. В общем офлайн-меню эта кнопка открывает список архивов текущего аккаунта. Кнопка «Поделиться ZIP» передаёт выбранный архив через системное меню Android. Просмотр архива не делает сетевых запросов и не изменяет лайки.

Уже загруженные видео автоматически не догружаются: сохранение применяется к следующим событиям успешной загрузки. Для ошибок показано сообщение; повторите загрузку с интернетом. Архивы остаются доступны после отключения сохранения.

Проверки: компиляция Java/DEX, сборка изменённых нативных классов, повторное применение патчей; тесты пагинации, числа лайков, удаления повторов, ошибок API и чтения ZIP/JSON. Работа штатного сетевого API и внешний вид на реальном телефоне требуют проверки APK.
