# Исправление появления музыкального островка

Изменено только распознавание открытого профиля. UID берётся из модели видимой шапки TikTok 47.2.41 (`Up().t43()`), поэтому обычное имя без привязки значка не скрывает плеер. Скрытые заранее загруженные шапки больше не вытесняют открытую. Поддержан основной и резервный компонент шапки V2.

Сохранены отключение островка пользователем, приватность чужой музыки, скрытие в ленте, настройках и фоне. Дизайн, музыка и сервер не изменены.

Пройдено пять целевых тестов и полная компиляция Java/D8 API 23. Новый тест воспроизводит ошибку на исходном коде и проходит после исправления. APK не собирался; на физическом телефоне не проверено.

В присланном архиве с именем 0.6.7.1 исходно находятся папка `ttcuz-project-v0.6.6.3`, `VERSION` = 0.6.6.1 и `version.json` = 0.6.6.2. Они сохранены без изменения: этот ZIP содержит только запрошенное исправление.
