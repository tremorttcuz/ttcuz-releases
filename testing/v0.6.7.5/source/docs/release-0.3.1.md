# ttcuz 0.3.1

## Изменения

- Автоподтверждение: убраны промежуточные всплывающие ошибки; уведомление появляется один раз после положительного ответа сервера и восстановления описания.
- Сервер проверки запрашивает свежую страницу профиля без кеша.
- Автопродление: исправлен выбор штатного отправителя стикеров; добавлено время отправки отдельно для каждого аккаунта, защита повторов по календарному дню. Время входит в резервную копию.
- Комментарии: удержание текста открывает копирование без имени автора и выбор фрагмента; сохранён доступ к штатному меню.
- Даты: привязка к видимой карточке, поддержка фото-постов без штатной строки, восстановление после смены карточки. В комментариях дата скрыта.
- Акцент: подключено перекрашивание розовых иконок через штатный tint; сохранён отдельный цвет большого лайка. В HSV добавлены яркие образцы.
- Меню: компактные группы и отступы по приложенному видео.
- Баннеры и голосовые комментарии: проверены переключатели Anti A/B и нативные чтения флагов; изменения требуют перезапуска.

## Как использовать

Автопродление: выбрать стикер в избранном, открыть нужные чаты для получения актуального состояния серии; в настройках серии выбрать «Время отправки». «Без расписания» отправляет, когда серия ждёт продления. Время определяется часовым поясом устройства. Режим проверяет необходимость продления, а не рассылает сообщения всем ежедневно.

Копирование: включить копирование комментариев, удержать сам текст, выбрать «Копировать» или «Выделить текст». Имя автора не включается.

## Что проверено

166 клиентских тестов (полный прогон 165 и дополнительная проверка иконки), 23 серверных теста; компиляция DEX. Перехваты меню комментария собраны в smali и проверены на повторное применение. Аргументы отправителя сверены с TikTok 47.2.41.

## Что ещё требует проверки

Это архив исходников проекта, не установочный APK. Серверные изменения в server/cloudflare/profiles.mjs не опубликованы: их нужно развернуть на Worker. Успех подтверждения зависит от доступности публичного профиля серверу; недоступность не выдаётся за подтверждение.

Автопродление работает при живом процессе TikTok, выбранном стикере и известном чате со свежим состоянием серии. Работа после принудительного закрытия приложения не реализована; реальная доставка на телефоне не проверена.

Дата показывается, когда модель поста содержит время публикации. Неизвестное время не заменяется выдуманным. Все типы нативных раскладок на устройстве ещё нужно проверить.

Перекрашивание охватывает розовую/красную семью интерфейса. Отмеченный серый активный дизлайк и отдельные бирюзовые элементы не подтверждены как исправленные: нельзя надёжно перекрасить их глобально без изменения остальных нейтральных значков. Клавиатура принадлежит отдельному приложению IME.

Баннеры и голосовые комментарии включают существующие клиентские флаги; доступность серверных возможностей TikTok не гарантируется флагом.
