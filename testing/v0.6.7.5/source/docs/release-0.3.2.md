# ttcuz 0.3.2

- Доработан акцент выбранного дизлайка: штатный контроллер реакции, без перекрашивания нейтральной иконки.
- Добавлен перехват цвета иконок из ресурсов, включая пути, обходившие прямой tint. Добавлены штатные бирюзовые акценты, альфа сохраняется; расширены обработчики текста, фонов, кистей и градиентов.
- Простое меню с компактными группами по видео сохранено. В разделе плагинов добавлен редактор.
- Плагины-команды: вставка и редактирование исходника, проверка, запуск без сборки, выключение, удаление и копирование. Кнопки с окнами/сообщениями/копированием, замена имён по ID и цветов.
- Серверная очередь: до одобрения плагин не доступен другим; изменения проходят проверку снова. Проверены ограничения, отклонение, целостность и запрет одобрения без входа/токена.
- API 5 для обычных плагинов: сведения о текущем ролике, строковые настройки и окно выбора.

Проверено: полный прогон 173 тестов и дополнительный тест HTTP-маршрутов; DEX компилируется, все целевые методы найдены. Нативный перехват дизлайка собран в smali и проверен на повторное применение.

Это архив проекта, не установочный APK. Сервер магазина необходимо обновить отдельно; сейчас публикация не развёрнута. Без сборки работают JSON-команды. Java/JavaScript редактор не исполняет. Меню упрощено по референсу; точное визуальное совпадение всех отмеченных элементов на телефоне не проверено.

Инструкция: docs/plugin-editor.md. Пример: examples/commands-plugin.json.
