# UI 0.2.21

Plexus — нативный Canvas позади прозрачного ScrollView настроек. 28 частиц в фиксированных float-массивах, максимум 56 связей, 378 проверок расстояния, интервал 33 мс. Host только наблюдает касания и возвращает исходный результат dispatchTouchEvent: кнопки и прокрутка сохраняются. Ближайшая точка в радиусе 80 dp двигается вслед за пальцем; на границах координаты ограничены.

Состояние theme_plexus хранится в AccountAppearance. Эффект выключается через «Оформление → Фон Plexus». Локальная очередь кадров удаляется при onPause, onDestroy, onDetachedFromWindow и невидимом окне. Системное отключение анимации оставляет статичный фон. Бледные связи и маленькие точки не подменяют текст/контролы. Инициализация массива происходит только при размере View; Canvas и Paint переиспользуются.

Пилюля всех загрузок через Screen.progress: обновления, плагины магазина и PluginContext.download. Надпись «Загрузка» центрирована; название задания доступно диктору. Нативные загрузки TikTok, не проходящие через Screen.progress, этим изменением не переписаны. Отрисовка волны/PNG-морфа сохранена; контур стабильной пилюли кэшируется.

134 теста Python/Java и компиляция Java/DEX. Тесты проверяют алгоритмы и жизненный цикл, а не FPS физического телефона. Сетевые и серверные ограничения 0.2.20 сохраняются.
