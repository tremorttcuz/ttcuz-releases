# ttcuz: текстурпаки и плагины

Материал для страницы проекта ttcuz. Форматы ниже относятся к сборке TikTok 47.2.41.

## Текстурпак

1. Откройте **ttcuz → Текстурпаки → Выгрузить картинки**. Приложение создаст архив `.cuztx` в папке загрузок.
2. Распакуйте архив и замените только нужные изображения или анимации. Сохраните пути внутри `res/` и `assets/` без переименования.
3. Удалите неизменённые файлы. Оставьте `manifest.json` в корне архива.
4. Запакуйте содержимое обратно в ZIP и дайте файлу расширение `.cuztx`.
5. Откройте **ttcuz → Текстурпаки → Установить** и выберите файл.

Пример `manifest.json`:

```json
{
  "name": "Мой набор",
  "author": "Имя автора",
  "about": "Краткое описание",
  "tiktok": "47.2.41"
}
```

Поле `tiktok` связывает набор с конкретной версией приложения. Если пути ресурсов изменятся в другой версии, набор может отобразиться частично. Подробности: [textures.md](textures.md).

## Плагин

Плагин `.ctt` — ZIP с `manifest.json` и `classes.dex` в корне. `icon.png` можно добавить по желанию.

```text
my-plugin.ctt
├── manifest.json
├── classes.dex
└── icon.png
```

Пример манифеста:

```json
{
  "id": "ttcuz.example",
  "name": "Пример",
  "name_ru": "Пример",
  "version": "1.0",
  "author": "Имя автора",
  "description": "Что делает плагин",
  "description_ru": "Что делает плагин",
  "entry": "example.ttcuz.Plugin",
  "min_api": 1
}
```

Установите файл через **ttcuz → Плагины → Установить плагин**. Плагин работает с правами приложения, поэтому устанавливайте только проверенный код. Полное описание API и сборки: [plugins.md](plugins.md).
