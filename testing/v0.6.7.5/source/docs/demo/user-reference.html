Очередь
Так твоя музыка лежит на сервере: обычный текст со ссылкой на звук, самого аудио там нет. На новом телефоне звук заново скачивается по ссылке. Читает файл только владелец.




Звук в демо синтезируется в браузере, поэтому спектр настоящий. В приложении играет звук из видео, а на сервере хранится только текст: название и ссылка.
