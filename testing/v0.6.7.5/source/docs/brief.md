# PROMPT: Полный ребрендинг и переработка MargyT → ttcuz

Ты работаешь с исходниками существующего TikTok-мода MargyT. Задача: не делать отдельное приложение с нуля, а качественно переработать текущий проект, сохранив рабочую архитектуру, хуки и систему плагинов, но полностью убрать старый брендинг и превратить мод в **ttcuz** с глубокой кастомизацией.

## Главная цель

Сделай из текущего MargyT новый мод **ttcuz**:

- новый бренд и имя `ttcuz`;
- новая иконка приложения из `assets/ttcuz-icon.png`;
- полностью настраиваемая тема TikTok;
- кастомизация шрифтов;
- смена emoji-паков;
- кастомные значки рядом с ником и оформление ника, синхронизируемые между пользователями ttcuz;
- настройка цвета лайков;
- сохранение системы плагинов;
- сохранение полезных функций мода;
- исправление багов и неровностей интерфейса;
- качественные, аккуратные анимации;
- стабильная работа без визуальных регрессий.

Не делай временные заглушки. Все функции должны быть реально интегрированы в существующий код и работать после сборки.

- видео-контент;
- photo posts;
- carousel images;
- Live Photo;

- обрезать UI;
- вызывать дрожание;
- менять touch targets;
- ломать hitbox кнопок;
- затрагивать media transforms.

- не делать сетевые запросы на main thread;
- использовать debounce/throttle там, где нужно;
- не добавлять глобальный polling без необходимости.

Следить за:

- dropped frames;
- memory usage;
- bitmap leaks;
- lifecycle leaks;
- ANR;
- crashes.

# 18. Синхронизация ttcuz profile styles

Для функций, которые должны видеть другие пользователи ttcuz, сделай отдельный модуль, условно:

`TtcuzProfileSync`

Он хранит только данные кастомизации ttcuz.

Пример структуры:

```json
{
  "profileId": "...",
  "badge": {
    "type": "image",
    "assetId": "..."
  },
  "nicknameStyle": {
    "mode": "gradient",
    "colors": ["#FFFFFF", "#999999"],
    "angle": 45,
    "animated": false
  },
  "updatedAt": 0
}
```

Не включать в эту систему пароли, auth tokens, cookies или приватные TikTok session data.

Сделать:

- opt-in;
- local cache;
- timeout;
- fallback;
- validation;
- max payload size;
- server response validation;
- graceful offline mode.

Если backend в репозитории отсутствует, подготовь чистый interface/provider abstraction и отдельный backend module/API contract, чтобы его можно было подключить без переписывания UI.
