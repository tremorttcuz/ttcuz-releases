# Обновление сервера значков для 0.1.8

Клиент и сервер находятся в этом ZIP. 3 октября 2026 рабочая D1 обновлена миграциями 0002 и 0003, Worker опубликован (6c348c8b-8b98-446f-84ea-43d0c98f4f01). Каталог отвечает 200. Инструкция ниже нужна для другой базы/установки.

Из каталога server/cloudflare с подключённым аккаунтом Cloudflare:

```sh
npx wrangler d1 execute ttcuz-profiles --remote --file=migrations/0002_profile_verified.sql
npx wrangler d1 execute ttcuz-profiles --remote --file=migrations/0003_custom_badges.sql
npx wrangler deploy --dry-run
npx wrangler deploy
```

Миграция идемпотентна, существующие значки и профили сохраняются. Для новой базы сначала используется schema.sql. Новое правило run_worker_first включает /badges/*, чтобы картинки из D1 обслуживал Worker.

Проверка после обновления: GET /v1/badge-catalog отдаёт стандартные и загруженные значки. В подтверждённом аккаунте администратора откройте «Выдать значок» → «Добавить свою картинку». После выбора файла задайте название и нажмите «Добавить в каталог». Затем выберите значок и получателя.

Выдача по UID поддерживалась старым сервером и работает без поиска публичной страницы TikTok. При поиске по нику TikTok может блокировать запросы Worker: откройте профиль получателя в приложении, вернитесь в меню и повторите, либо введите UID. Ники не обрезаются; ссылки на чужие домены и видео не принимаются.

Если сервер требует подтверждения администратора, приложение сбрасывает устаревший локальный флаг. Нажмите «Подтвердить аккаунт администратора» и выполните проверку через описание своего TikTok. Права администратора не обходятся.

Загрузка картинок ограничена подтверждённым создателем с прежним UID. PNG хранится в D1; получатели получают тот же значок через публичный /badges. Цвета исходной картинки сохраняются. До обновления Worker новая загрузка не заработает: приложение покажет необходимость обновления сервера.
