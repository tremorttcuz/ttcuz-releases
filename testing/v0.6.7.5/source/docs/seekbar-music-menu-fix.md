# Перемотка и раздел «Музыка» — 0.6.7.3

## Изменения

- В главном списке настроек есть отдельная строка **«Музыка»**. Внутри: включение островка, «Добавить свой звук» с рекомендациями и своей подборкой, положение/публикация в профиле и оформление плеера. Поиск, обучение и чипы переходят в этот раздел.
- Для обычных видео недостаточно `setSeekBarShowType(0)`: в TikTok 47.2.41 контроллер отдельно проверяет эксперимент возможности перетаскивания, `VideoControl.showProgressBar` и эксперимент обратной перемотки. Когда эти проверки отказывают, нативный код скрывает полосу ещё до установки её режима. Мод теперь учитывает все три проверки при включённой настройке.
- Сохранены нативные проверки LIVE, фото, специальных рекламных карточек, текущего ролика, состояния воспроизведения, Stories и закрывающих видео экранов. Патч не делает LIVE или фотографию перематываемым видео.
- Нативные активные режимы 1/2/100/101/102 сохраняются; скрытые режимы 3/4 становятся видимыми. Отложенное обновление больше не заменяет новое состояние перетаскивания устаревшим.
- Показ полосы включён по умолчанию. Ранее сохранённый выбор «выключено» сохраняется: включите **«Лента и видео» → «Перемотка на всех видео»**, если эта настройка была выключена. Импорт и сброс настроек теперь обновляют её без перезапуска.
- Музыкальный слайдер отдаёт перетаскивание родному SeekBar и удерживает жест внутри прокручиваемого меню. Невидимый нативный бегунок получил правильный размер, соответствующий нарисованной ручке.

Исправление подключения островка к реальной шапке профиля из предыдущего архива сохранено. Код антивыгорания и скруглений сетки не менялся.

## Проверки

- Все 240 тестов проекта прошли, включая новые проверки нативных условий, режимов перемотки, применения настроек и жеста музыкального слайдера.
- На предыдущем архиве воспроизведено выключение полосы по умолчанию; новые проверки нативных условий в нём отсутствуют.
- Полный исходный `classes35.dex` из TikTok 47.2.41 разобран штатным патчером, исправлен, собран для API 23 и разобран повторно. Все три новых вызова сохранились, повторное применение их не дублирует.
- Java-код проекта скомпилирован в DEX; найдены все 210 обязательных методов патчера.
- Архив проверен по CRC и по содержимому каждого исходного файла; изменения ограничены перечисленными файлами и новыми тестами/отчётом.

## Применение

Это ZIP проекта для сборки, не готовый APK. Собирайте из папки `ttcuz-project-v0.6.7.3` и используйте прежний ключ подписи для обновления установленного мода. Первая сборка обновит ключ DEX-кэша из-за новых правил; прежний совместимый кэш для затронутых классов исключён. Антивыгорание, Grid и серверные файлы сохранены из исходной версии.

После установки откройте обычное видео и перетащите нижнюю полосу. Проверьте короткое и длинное видео, видео из профиля и поиск; затем перетаскивание прогресса музыкального плеера. На физическом Android-устройстве эта версия не проверена, поэтому универсальная работоспособность на всех клиентах не подтверждена.
