# 0.6.7.4 — состояние сборки

## Изменения

Удалён весь встроенный музыкальный плеер и обучение ему. Сохранены скачивание аудио и DownloadIsland. Старые локальные аудиофайлы и списки пользователя автоматически не удаляются. Серверные маршруты музыки сохранены для старых клиентов; новый клиент ими не пользуется. При очередной публикации оформления клиент отправляет `musicOn: false`, чтобы старые версии не показывали удалённый островок. Параметр `profileLayout` продолжает читаться и публиковаться независимо от музыки.

Убрана полоска chips над разделами. `accentTonal()` сохранён, поскольку используется кнопками в других местах.

На странице видео с полем «Найти связанный контент» глаз центрируется под стрелкой «Назад», с отступом 6 dp от её нижнего края. Если стрелка недоступна, используется левый край 4 dp и положение ниже верхнего заголовка. Позиции ленты, «Входящих» и других страниц видео сохранены.

## Индикатор

Геометрия M3Shapes и параметры MD3Spinner перенесены из предоставленного `m3tok.zip`, `java/plugins/leo/expressiveTok.java` (автор в manifest.json: leonidtsk). Семь форм, интервал 650 мс, пружина damping=0.6/stiffness=200 и вращение за 4666 мс. Это перенос геометрии из плагина, а не зависимость от библиотеки Material Components.

В реальном APK 47.2.41 индикатор — `com.bytedance.tux.status.loading.TuxSpinner` (classes5.dex), drawable точек — `X.0DiZ`. Указанный в плагине `X.0WgH` здесь наследует Object и не является View. Патч заменяет только метод onDraw TuxSpinner; видимость, положение, размеры и жизненный цикл остаются нативными. Совпадение хука обязательно для сборки; старый DEX-кэш для него не используется. Цвет берётся из Accent.colour() при каждой отрисовке. При отключении анимаций показывается первая неподвижная форма.

## Проверки

- `python -m unittest discover -s tests`: 241 тест, OK. Включены Expressive, Motion, Screen/DownloadIsland, перенос глаза, MD3, совместимость профилей и отсутствие музыкального плеера.
- Код мода заново скомпилирован с настоящим android.jar Android API 35, D8 для minSdk 23, DEX 035. Все 216 методов, необходимых патчеру, определены.
- APK собран на основе оригинального TikTok 47.2.41. Ресурсы и весь код мода пересобраны; 52 нативных DEX использованы из ранее успешно собранной 0.6.7.3, поскольку её исходные правила патчера совпадают с входным ZIP. Изменённый classes5.dex заново разобран и собран с единственным новым хуком MD3. Старый DEX кода мода исключён и заменён новым classes54.dex.
- Сохранение нативных DEX проверено побайтово; 13 непатченных DEX предыдущего APK совпадают с исходным официальным APK. DownloadIsland.java побайтово совпадает с входным ZIP.
- Проверены CRC APK, подписи v1/v2/v3 и zipalign. Сертификат совпадает с 0.6.7.3. Android versionCode повышен с 2030709413 до 2030709414.
- Логи и происхождение повторно использованного кода: `verification/0.6.7.4/`. Это инкрементальная сборка нативных подключений; исходники содержат полноценный патчер для обычной сборки с нуля.

Физический Android-телефон не проверен. Визуальный контраст, касания, смена иконки, позиция глаза и серверное принятие длинных текстов требуют проверки на устройстве. Предположение из входного WIP о причине вылета при смене иконки не считается подтверждённым исправлением причины.
