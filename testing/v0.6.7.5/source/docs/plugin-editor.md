# Редактор и магазин плагинов

## На устройстве

В «Плагины → Добавить плагин → Создать» откроется редактор команд. В нём можно изменить ID, название, версию, автора, выбрать или удалить иконку, добавить и удалить команды. Для имён и подмены цветов доступен дополнительный JSON. Сохранение проверяет формат и включает командный плагин.

Обычный `.ctt` сначала устанавливается через «Установить файл». Удержание его строки открывает редактор названия, версии, автора, описания и иконки. Исполняемый DEX сохраняется; после изменения плагин выключен и проходит обычную проверку перед включением.

Иконки преобразуются в PNG с максимальной стороной 64 пикселя. Пропорции и прозрачность сохраняются. Для командного плагина поле `icon` содержит PNG в base64; общий размер JSON — до 64 КБ.

## Создателю

Для активного аккаунта `7491898648855512119` доступны «Управление магазином» и «Опубликовать в магазине» в редакторе. Командные плагины можно создавать, редактировать, публиковать и удалять. Установленные `.ctt`, включая скачанные, можно редактировать и публиковать. В управлении магазином доступны также поступившие на проверку команды.

Сервер сверяет ключ устройства с подтверждённым профилем создателя. UID и значок сами по себе не дают права на публикацию. Общий администраторский секрет в APK не хранится.

## Сервер

Миграции `0006-script-plugins.sql` и `0007-plugin-store.sql` создают таблицы команд и архивов. Приложение использует `POST /plugins/admin` для списка, публикации и удаления. Общедоступные адреса: `/plugins/catalog.json`, `/plugins/scripts` и `/plugins/files/<id>/archive.ctt`.

Для бесплатного хранилища D1 `.ctt` ограничен 1 МБ. Установка на устройстве сохраняет прежний предел исполняемого DEX. SHA-256 каталога вычисляется по точным байтам загруженного архива; загрузчик сверяет его перед установкой. После установки обычный плагин остаётся выключенным.

## Редактор 0.6.5.9-fixed7

Компактный экран: слева серый квадрат с плюсом для иконки, справа название, версия и автор. Кнопки, имена и цвета добавляются круглым «+» рядом с заголовком блока, без JSON. «Сохранить» и «В магазин» закреплены внизу. Создатель может выложить `.ctt` без установки: «Управление магазином → Добавить файл .ctt». Макет экрана: `docs/plugin-editor-demo.html`.
