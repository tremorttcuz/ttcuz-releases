# Доводка ttcuz до 1.0

1. Зафиксировать список поддерживаемых функций и версию TikTok. Для каждой функции описать ожидаемое поведение и ограничения. Не выпускать неработающую опцию как готовую.
2. Устранить воспроизводимые вылеты. Проверять изменение каждой настройки в готовом APK, повторные нажатия, возврат после сворачивания, перезапуск и смену аккаунта. Тесты Java со заглушками не заменяют эту проверку.
3. Проверить ключевые сценарии на устройствах: видео / живые фото / комментарии; фиксация 2×; фоновые загрузки; проверка профиля и выдача значков; синхронизация и отдельное оформление аккаунтов. Текстовое автопродление сейчас не реализовано.
4. Профилировать готовый APK при прокрутке комментариев, включённом антивыгорании и анимациях. Сравнивать с исходным TikTok на том же устройстве. Исключить повторные обходы дерева, лишние выделения памяти, запросы и работающие в фоне аниматоры; измерить результат.
5. Сохранить один язык интерфейса: M3, согласованные отступы, размеры иконок, радиусы и высоты кнопок. Цветом выделять действие и состояние. Анимации объясняют переходы и поддерживают отключённое движение; фон не конкурирует с текстом. Проверять длинные подписи, крупный системный шрифт, светлую / тёмную тему и собственные шрифты.
6. Провести закрытую бету, затем выпустить кандидат 1.0 с исправлением ошибок без новых функций. Проверить установку поверх предыдущей версии, сохранение настроек, резервную копию и совместимость сервера. Выпускать 1.0 после прохождения сценариев, а не просто смены номера.

Готовность: нет воспроизводимых блокирующих вылетов; заявленные функции проверены в установленном APK; ограничения описаны; нет неподтверждённых обещаний о подмене региона или доставке сообщений.
