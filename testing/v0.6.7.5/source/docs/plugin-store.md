# Магазин и проверка плагинов · 0.2.38

Каталог ttcuz подключён по умолчанию: `https://ttcuz.daniilsolovatulin.workers.dev/plugins/catalog.json`. Пользователь может указать другой HTTPS JSON-каталог или очистить адрес, чтобы отключить магазин. Сервер командных плагинов находится по соседнему пути `/plugins/scripts`; сервер профиля используется как D1-хранилище, но данные разделены по таблицам.

Минимальный JSON: `{"plugins":[]}`. Пример находится в `examples/plugin-catalog.json`.

Запись каталога:

```json
{
  "plugins": [{
    "id": "example.plugin",
    "name": "Название",
    "version": "1.0",
    "author": "Автор",
    "about": "Что делает плагин",
    "tiktok": "47.2.41",
    "url": "files/example.plugin.ctt",
    "icon": "icons/example.png",
    "sha256": "ЗДЕСЬ_64_ШЕСТНАДЦАТЕРИЧНЫХ_СИМВОЛА"
  }]
}
```

Относительные ссылки разрешаются относительно адреса каталога. И каталог, и картинки, и файлы должны использовать HTTPS без логина/пароля в URL. ID: до 80 латинских букв, цифр, точек, подчёркиваний и дефисов; первая позиция — буква или цифра. Не более 100 записей. Записи без корректного SHA-256 или URL не предлагаются. SHA-256 считается от полного .ctt, например `Get-FileHash -Algorithm SHA256 -LiteralPath ./example.plugin.ctt` в PowerShell. Хеш в каталоге проверяет соответствие полученному файлу, но сам по себе не подтверждает личность автора или безопасность.

Скачивание ограничено 18 MiB. Архив плоский: manifest.json (64 KiB), classes.dex (16 MiB), необязательный icon.png (1 MiB). Дубликаты, каталоги, нативные библиотеки и любые остальные файлы запрещены. Плагин не выполняется во время анализа. Его ID сверяется с каталогом; совместимость берётся также из manifest.json. После установки он выключен.

Перед включением: анализ заголовка DEX, Adler-32, SHA-1 внутренней целостности, таблиц типов/методов и native-флагов. Shell/Runtime.exec, ProcessBuilder.start, load/loadLibrary, Dalvik DEX/ClassLoader и native-методы блокируются. Сеть (в том числе API мода), рефлексия, WebView, доступ к файлам, контактам/телефонии, буферу обмена и контексту TikTok требуют подтверждения. Проверка повторяется при запуске; подтверждение привязано к отпечатку DEX, manifest и иконки. Замена пакета после отчёта не принимается.

Это консервативный статический анализ, а не антивирус и не песочница. Упоминание API показывает возможность, а не доказывает злой умысел. Обфускация, непрямые вызовы, собственные сетевые обёртки и выполнение через рефлексию могут скрывать действия. Плагины исполняются в процессе TikTok с его правами. Отсутствие известных индикаторов не означает безопасность. Android проверяет пригодность байткода при загрузке; анализатор не заменяет полный верификатор ART.

Основа формата: [DEX, Android Open Source Project](https://source.android.com/docs/core/runtime/dex-format). Ограничения загрузки стороннего кода: [Android Developers](https://developer.android.com/privacy-and-security/risks/dynamic-code-loading).

Проверки в проекте: `tests/test_plugin_audit_runtime.py`, `tests/test_badge_placement_runtime.py` и `tests/plugins-server.test.mjs`. Каталог команд принимает заявки, но публикует только вручную одобренные версии. Администрирование: GET `/plugins/scripts/admin/pending` с `Authorization: Bearer <CRASH_ADMIN_TOKEN>`; POST `/plugins/scripts/admin/review` с JSON `{"digest":"…","action":"approve"}` или `reject`.

## Размещение бинарных `.ctt`

Worker отдаёт `public/plugins/catalog.json`. Сам файл `.ctt` храните как asset GitHub Release, затем добавьте в каталог запись с прямой HTTPS-ссылкой и SHA-256 полного архива; `icon` можно оставить пустым. Список ограничен 100 записями, размер загрузки в приложении — 18 MiB. После изменения `catalog.json` разверните Worker. Подписанный/проверенный пакет и статический анализ всё равно не гарантируют безопасность стороннего кода.

## Правило публикации

Обфускация запрещена. Сохраняйте понятные имена классов и методов, атрибут SourceFile и читаемые исходники; отключите переименование R8/ProGuard. Пакеты с удалённым SourceFile, непрозрачными короткими/хешированными именами, управляющими символами или длинными закодированными строками отклоняются. Проверка намеренно консервативная: допустимые длинные base64-данные тоже могут отклоняться. Проверяйте отчёт и исправляйте пакет, не обходите анализатор.

Это правило для всех способов обфускации, но автоматический анализ распознаёт только перечисленные признаки. Сохранение имён само по себе не доказывает отсутствие сокрытия кода; гарантии распознавания любой обфускации нет. Для строгой модерации нужны также исходники и проверяемая сборка.

В `server/badges.py` приём, каталог и скачивание пакетов используют `server/plugin_audit.py`. Для подключения перенесите оба файла на сервер и перезапустите сервис. Уже опубликованные пакеты повторно проверяются и исключаются при отказе. URL клиента для каталога остаётся настраиваемым; сервер не развёрнут автоматически.
