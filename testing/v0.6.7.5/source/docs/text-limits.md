# Лимиты ввода — 0.6.7.5

В «Лента и видео» добавлен раздел «Лимиты ввода» с тремя независимыми переключателями:

- Комментарии без ограничения длины.
- Репосты без ограничения длины.
- Любое число хештегов в видео.

Все три выключены по умолчанию. После включения закройте поле ввода и откройте заново. Для хештегов откройте редактор заново. Настройки сохраняются, входят в резервную копию и сброс раздела. Используются существующие MD3 строки, анимированные переключатели и цвета темы; добавлен векторный значок хештега.

## Найдено в реальном APK TikTok 47.2.41

- Обычный лимит комментариев: `X.0onX.LIZIZ()` читает `CommentCharLimitConfig.charLimit`. Его результат теперь проходит через переключатель.
- Длинные комментарии: восемь чтений `LongCommentWritingConfig.maxInputLimit` — клавиатура, вставка упоминаний/эмодзи и проверки. Вместо `Long.MAX_VALUE` используется `Integer.MAX_VALUE`, потому что приложение переводит лимит в int; иначе получалось бы -1.
- Новая форма репоста: три чтения ленивого `X.08uW.LIZ`, связанного с `repost_text_max_length`. Результат меняется после чтения кэша, поэтому настройка мода не застывает вместе с экспериментом TikTok.
- Старая форма репоста: отдельный конструктор фильтра `X.0HvS` и жёсткие 30 символов в фильтре `X.0H5v`. Учтены обе ветви выбора фильтра.
- Хештеги: `w3j.e.LIZ()` и `LIZJ()` читают `studio_publish_hashtag_max_limit` и `studio_publish_limit_hashtag_switch`. Этим провайдером пользуются редактор `shortvideo.l5`, слушатели TitleModule, AVPublishServiceImpl и проверка перед публикацией `X.0YLW`. Отключается проверка количества; сами хештеги и их данные сохраняются.

Патч сохраняет другие фильтры, текст публикаций, упоминания, правила отдельных хештегов, длину подписи видео, нативную отправку и обработку ошибок. Это снятие локальных ограничений, а не подмена результата отправки.

## Проверки

- Проверки исходной реализации 0.6.7.3: все 243 теста прошли. Актуальные результаты 0.6.7.5 приведены в [release-0.6.7.5](release-0.6.7.5.md). Новые проверки используют фрагменты именно APK 47.2.41 с директивами `.line`, обе формы репоста, независимость настроек, выключение и совместимость длинного лимита с int.
- Полные `classes15.dex` и `classes23.dex` с новыми изменениями собраны для API 23. Классы фильтров из `classes7.dex` также собраны. Изменённые классы разобраны повторно: все 16 новых вызовов сохранились и повторно не вставляются.
- Java-код мода скомпилирован в DEX; все 215 требуемых методов патчера найдены.
- Сборщик требует все семь видов новых подключений и не использует старый совместимый кэш для затронутых классов. Если их не найдёт, сборка остановится вместо выдачи неработающих переключателей.
- Архив проверен по CRC и сохранению всех остальных исходных файлов, включая перемотку, антивыгорание, сетку и серверные файлы. Музыкальный островок удалён в 0.6.7.4.

## Установка и пределы проверки

Это ZIP исходного проекта для сборки, не готовый APK. Соберите мод из папки `ttcuz-project-v0.6.7.5` с прежним ключом подписи, установите обновление и включите нужные функции в настройках. Кэш для новых правил пересоздастся автоматически.

Работа на физическом Android-устройстве и принятие длинных текстов сервером TikTok не проверены. Сервер может отклонить отправку; мод показывает нативный результат, не сообщает ложный успех. Совместимость новых правил подтверждена для исходного APK 47.2.41, для других версий не подтверждена.
