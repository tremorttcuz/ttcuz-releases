# Коллекция иконок ttcuz

Каждая иконка — папка `assets/icons/<id>/`:

| файл | назначение |
|---|---|
| `icon.png` | 1024×1024, полная иконка (legacy launcher, превью в настройках, about, splash) |
| `foreground.png` | 432×432, прозрачный слой для adaptive icon (контент уже вписан в safe zone) |
| `monochrome.png` | 432×432, белый силуэт на прозрачном для themed icons (Android 13+) |

Фон adaptive-иконки — цвет `adaptive.backgroundColor` из `manifest.json`.

## Как добавить новую иконку
1. Создать папку `assets/icons/<новый-id>/` с тремя файлами выше.
2. Добавить запись в `manifest.json` (`id`, `label`, `icon`, `adaptive.*`, `default: false`).
3. Код менять не нужно: список иконок в настройках и activity-alias-ы должны строиться из манифеста.

## Текущие иконки
`ttcuz` (по умолчанию, градиент), `relief` (рельеф), `violet` (фиолет), `pixels` (пиксели) и `glitch` (глитч).

В настройках иконки показываются горизонтальной лентой, всегда раскрытой. Старая иконка `dotted` удалена: если она была выбрана, мод вернёт `ttcuz`.

## Иконка «Акцент» (красится под акцент)
`accent` — обычный пункт в ленте. Под ним в манифесте лежат 13 скрытых вариантов (`"auto": true`): 12 оттенков через 30° (`accent_h00`…`accent_h11`) и серый (`accent_gray`). В ленте они не показываются.

- Выбран «Акцент» → при смене акцента (`Accent.set` → `Launcher.followAccent`) через 0,6 с включается вариант, ближайший по оттенку. Приложение не перезапускается (`DONT_KILL_APP`), лаунчер обычно обновляет иконку за пару секунд.
- Превью в настройках рисуется вживую по точному акценту из двух слоёв (`art/layer_shape.png`, `art/layer_glyph.png`).
- Формула цветов одна и в `make_accent_icons.py`, и в `Launcher.tone()`: фон и знак — HSL(h, .50, .37), плашка — HSL(h, .78, .83); у серого насыщенность ×0,12.
- Пересобрать картинки: `python3 assets/icons/make_accent_icons.py` (исходник — `art/source.png`).
