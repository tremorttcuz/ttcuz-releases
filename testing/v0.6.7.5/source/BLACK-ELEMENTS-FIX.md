# Точечное исправление чёрных элементов

Основа: ttcuz-project-v0.6.5.10-download-compatible.zip. Предыдущие исправления сохранены.

Исправлены почти чёрные нейтральные цвета на подтверждённо тёмном фоне для кнопок комментария (медиа, эмодзи, упоминание), значков компактного меню сообщения, подписи репоста и строки «Плейлист • …». Цветные акценты, фотографии, видео, аватары и обычный текст сообщений не обрабатываются. Размеры и расположение элементов не изменены. Явные настройки цвета текста/контролов имеют приоритет.

Идентификаторы кнопок и подписи репоста сверены с BaseInputAssem и VideoRepostAssem версии 47.2.41. Для меню требуется несколько разных подписей действий; для плейлиста используется ограниченное совпадение подписи на русском/английском. Фон определяется по реальным одноцветным заливкам, с учётом прозрачности. Неизвестный фон оставляется без изменений. Исходные цвета возвращаются на светлом фоне и при повторном использовании элемента. Состояния и прозрачность текста сохраняются; недоступные для чтения наборы состояний не упрощаются.

Проверки: весь Java-код успешно компилируется; исполняемый тест контраста проверяет тёмный/светлый фон, возврат цветов, исключение медиа, акценты, прозрачность, состояния кнопок, отложенное появление и отсутствие повторных записей цвета. Общий прогон: 77 тестов, после обновления двух затронутых тестовых заглушек проходят 75; две прежние ошибки тестовых стендов ScriptRuntime/SocialLibrary остаются (не связаны с этой правкой). Дополнительно повторно прошли 8 тестов контраста и акцентов.

APK не собирался. На телефоне визуальная проверка не выполнялась; окончательный результат на конкретном устройстве нужно проверить после следующей сборки.
