Глаз на странице видео с полем «Найти связанный контент» расположен под стрелкой «Назад». Сохранены исправления контраста карточек, языка «Лимитов ввода», смены иконки после сворачивания и кнопок.

# ttcuz

Исходный проект мода TikTok на основе MargyT. Пакет Java `cat.narezany.margyt`, некоторые внутренние каталоги сохранены для совместимости. Форматы ttcuz: текстурпаки `.cuztx`, плагины `.ctt`. Пользовательское имя и графика нового мода — `ttcuz`. Исходная архитектура и сведения об авторах сохранены в [документации исходного проекта](docs/upstream-readme.md).

Целевая база: универсальный APK TikTok **47.2.41** (`com.zhiliaoapp.musically`, minSdk 23). Текущая версия исходников — **0.5.0**. Состояние сборки и проверки описано в [status](docs/status.md).

## Что находится в проекте

- `margyt/` — Python-патчер APK: манифест, ресурсы, иконка, поиск хуков и упаковка.
- `inject/java/` — код мода внутри TikTok. Имя пакета оставлено для совместимости старых плагинов.
- `assets/icons/manifest.json` — коллекция пяти иконок ttcuz; `dots` используется по умолчанию. Сборка добавляет четыре варианта в существующий выбор иконки, включая adaptive и monochrome слои.
- `server/cloudflare/` — Cloudflare Worker и D1 для профилей, автоматической проверки, публичной синхронизации оформления и выдачи значков.
- `docs/profile-sync.md` — протокол синхронизации стиля профиля и значков.
- `docs/status.md` — перечень готовых и непроверенных функций.
- `docs/brief.md` — предоставленное техническое задание.
- `tests/` — проверки патчера и формата ресурсов.

## Состояние функций

Версия 0.2.1 исправляет копирование комментариев: долгий тап по строке → «Копировать» берёт текст текущей модели, а не самый длинный элемент интерфейса. Ник не добавляется; короткие ответы, эмодзи и переводы строк сохраняются. Дата публикации берётся из createTime именно открываемого поста и добавляется в подпись. Подключение к старым gates 0QeW удалено: в 47.2.41 это уже другой класс. Включение перемотки обновляет известные полосы сразу; дата появляется при следующем открытии видео. Превью сохраняет общий путь рисования значков и использует размер/шрифт/межбуквенный интервал настоящего заголовка, когда он обнаружен. Фиксированная высота строки удалена. Без обнаруженного заголовка используется размер 24 sp; соответствие геометрии на устройстве не подтверждено.

Версия 0.2.0 заменяет текстовые стрелки на векторные без ножки; стрелка поворачивается вместе с раскрытием блока. В палитре выбранный цвет становится скруглённым квадратом с обводкой, остальные остаются кругами. С тумблеров убраны галочки. Длинные пояснения вынесены в «Подсказки». Четыре шага обучения автоматически появляются при первом входе на основной экран; их можно пропустить и повторить через «Обучение» на главной странице настроек мода.

Версия 0.1.9 добавляет согласованное появление панелей снизу (280 мс), закрытие (180 мс) и плавное затемнение фона. Баннер перезапуска появляется один раз, остаётся на месте при обновлении меню и использует векторную иконку из assets/ui/restart.svg. Прозрачность, её уровень, пиксельный сдвиг и его амплитуда применяются без перезапуска; остальные настройки сохраняют прежние требования. Отключение анимаций в Android учитывается.

Версия 0.1.8 обновляет меню: разделы с нумерацией и ясной иерархией, короткие переходы, отклик на нажатия и собственные нижние панели для выбора и подтверждения. Администратор может выдавать значки по @нику, ссылке или UID и добавлять свои картинки в каталог. Для недавно открытого профиля используется UID, полученный из модели TikTok; сведения хранятся только в памяти до 10 минут. Ошибки сети, подтверждения администратора и поиска различаются. Прозрачность и сдвиг из 0.1.7 сохранены. Для нового каталога необходимы миграция и обновление Worker: [инструкция](docs/badge-catalog-deploy.md).

Для синхронизации нужны доступный Cloudflare Worker и подтверждение публичного описания TikTok с кодом; аккаунты и подтверждённый профиль здесь не обходятся. Отображение на реальном устройстве, а также синхронизация между двумя телефонами нельзя считать подтверждёнными одной проверкой исходников. Эмодзи-паки, для которых не предоставлены собственные ассеты, не включены.

## Сборка и проверка

`python -m unittest discover -s tests -v`

`node --test tests/*.test.mjs`

APK собирается из предоставленного пользователем TikTok 47.2.41 и подписывается локальным тестовым Android Debug сертификатом. Подпись отличается от официального TikTok, поэтому Android не установит его поверх официального приложения с тем же package ID; удаление приложения может удалить его локальные данные. Новая сборка и проверка функций на телефоне должны быть отмечены в [статусе](docs/status.md) отдельно.

Исходный проект распространяется с условиями, приведёнными в [upstream README](docs/upstream-readme.md). Права на TikTok и сторонние emoji-шрифты принадлежат их владельцам.


### Лимиты ввода — обновление 0.6.7.3

В **«Лента и видео» → «Лимиты ввода»** добавлены три независимых переключателя: символы комментариев, символы текста репоста и количество хештегов видео. По умолчанию выключены. После изменения закройте и снова откройте поле ввода или редактор. Настройки входят в резервную копию и сброс раздела.

Патч проверен по коду APK TikTok **47.2.41**: обычная конфигурация комментариев, длинные комментарии и вставка упоминаний, две формы репоста, редактор и проверка хештегов перед публикацией. Длина подписи видео, правила отдельных хештегов и ответы сервера сохраняются. Ограничения серверной отправки не проверены; снятие локального ограничения не гарантирует принятия любого текста сервером. Подробности: `docs/text-limits.md`.
