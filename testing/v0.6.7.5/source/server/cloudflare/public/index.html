Как создать пакет оформления или плагин для ttcuz. Автор проекта: @trem0r1_1.

Текстурпаки

В настройках ttcuz откройте «Текстурпаки» и экспортируйте текущий пакет. Полученный файл .cuztx используйте как образец: распакуйте его как ZIP, замените нужные изображения, сохраните структуру и упакуйте обратно.

  1. Оставьте прежние пути только для изменённых файлов; неизменённые удалите. Сохраните manifest.json в корне.
  2. Меняйте только те изображения, которые хотите заменить. Размер и прозрачность сохраняйте близкими к исходным.
  3. Переименуйте итоговый ZIP в .cuztx, импортируйте его в настройках и проверьте результат.

Рекомендуется сначала менять один элемент, затем добавлять остальные. Храните копию исходного пакета для отката.

Плагины

Плагин ttcuz — архив .ctt с manifest.json и classes.dex в корне. Он запускается внутри TikTok с его правами, поэтому устанавливайте только проверенный код.

my-plugin.ctt
├── manifest.json
├── classes.dex
└── icon.png (необязательно)

Класс entry из манифеста должен наследовать MargyPlugin. Установите архив в разделе «Плагины» и перезапустите TikTok для проверки.
