# ttcuz 0.6.7.5 — тестовая сборка

[Скачать ZIP исходников](ttcuz-project-v0.6.7.5.zip) · [Открыть исходники](source/) · [Результаты проверок](source/docs/release-0.6.7.5.md)

MD3 подключён ко всем найденным точечным загрузчикам TikTok 47.2.41: шесть нативных классов и 15 файлов Lottie-анимаций из assets и raw-ресурсов. Подключение в общем классе Lottie также охватывает композиции из потоков и кэша. Исправлен учёт открытых экранов при смене иконки. Сохранены изменения 0.6.7.4 и DownloadIsland.

243 автоматических теста прошли. Мод и изменённые нативные классы пересобраны с Android SDK; подписи APK и архивы проверены. Это инкрементальная сборка нативных подключений, её происхождение записано в результатах проверки. Проверки на физическом телефоне ещё не было.

Для тестов перейдите в `source/` и запустите `python -m unittest discover -s tests`. Для сборки следуйте README проекта. ZIP содержит исходники, а не готовый APK.
