ttcuz 0.6.7.8 · разработчикам

Руководство

Поддержка плагинов, JSON-команд, магазина и редактора удалена из приложения. Установленные пакеты не загружаются.

Прежние исходники и SDK сохранены в корневой папке plugins/legacy/, примеры — в examples/. Эти файлы не компилируются в APK. Серверные маршруты сохранены для прежних клиентов; отдельного развёртывания этого выпуска не было.

Сборщик: python -m ttcuz. Java-пакет: cat.ttcuz.framework. Проверки: python -m unittest discover -s tests.

Копирование и распространение оригинальных материалов ttcuz без письменного разрешения автора запрещено лицензией. Сторонние компоненты сохраняют свои условия.
