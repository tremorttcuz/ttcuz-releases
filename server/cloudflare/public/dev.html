ttcuz Plugin API 1

Собрать проект

Распакуй исходный ZIP. Нужны исходники ttcuz, JDK, Python, android.jar и r8.jar. SDK создаётся вместе с APK. 

python -m ttcuz.plugin ./my-project --sdk ttcuz-plugin-sdk.jar --android android.jar --r8 r8.jar -o my-plugin.ctt

Установка: настройки ttcuz → Плагины → Установить плагин.

Возможности

Java, Context приложения, настройки, файлы, потоки, жизненный цикл экранов, цвета, текст, имена, лента и события плагинов.

Главный класс наследует cat.ttcuz.framework.plugin.TtcuzPlugin. Подробный API и примеры находятся в docs/plugin-engine.md, examples/hello и examples/commands исходного архива.

Опубликовать

Отправь читаемый Java-код через редактор. Владелец получит заявку и разбор ИИ в Discord. Для проверенной публикации пакет собирает владелец из принятых исходников.

Старые плагины другого SDK нужно перенести на API ttcuz и пересобрать.
