# Синхронизация оформления профилей ttcuz

Сервер: https://ttcuz.ttcuz1337.workers.dev
Хранилище: Cloudflare D1 `ttcuz-profiles`, привязка `PROFILES`.

## Для пользователя

В разделе «Профиль» нажмите «Подтвердить профиль». Скопируйте временный код, добавьте его отдельной строкой в описание своего TikTok, укажите @ник и нажмите «Проверить». Сервер проверяет совпадение числового UID, ника и кода в описании публичного профиля. После подтверждения код можно удалить. Пароль, cookies и токены TikTok не передаются.

Включение общего оформления публикует значок, цвета ника, жирность, свечение, анимацию, её скорость, размер и положение значка. Другие пользователи должны иметь версию мода с этим механизмом. Изменения отправляются после короткой паузы; чтение кешируется на пять минут. Выключение отправляет запрос на скрытие публичного оформления. При ошибке сети отключение на сервере не гарантируется — проверьте статус отправки.

## Протокол

- `GET /v1/profiles/<uid>`: оформление или 404, если оно не опубликовано.
- `GET /v1/profiles/<uid>/badge`: PNG значка.
- `POST /v1/verify`: проверка публичного описания TikTok и привязка ключа устройства.
- `POST /v1/publish`: запись для подтверждённого владельца.
- `POST /v1/remove`: скрытие оформления и удаление изображения из публичной записи.

На телефоне генерируется случайный ключ 256 бит; сервер хранит только его SHA-256. На новом телефоне нужно подтвердить профиль заново; ключ старого телефона перестанет действовать. Значок PNG до 32 КиБ и 256×256, запрос до 64 КиБ. Проверяются диапазоны цветов, размеров и смещений. Ограничение: 20 запросов записи на IP за минуту.

## Проверка и ограничения

Java исходники прошли проверку компилятором без сборки APK. Пять тестов серверной части проверяют принадлежность кода конкретному профилю, ограничения параметров и запрет чужой записи. Публичный сервер отвечает на запросы чтения и отклоняет запись без подтверждения. Успешное подтверждение реального TikTok и отображение на двух телефонах ещё не проверены. TikTok может ограничить чтение публичной страницы; в этом случае проверка откажет и чужая запись не будет разрешена.

Магазин плагинов отложен. Документация опубликована на GitHub: https://github.com/tremorttcuz/ttcuz-releases; также доступна на Cloudflare и в проекте.
